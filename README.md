# Rainroji

Code-painted short films after Claude Monet: every frame is built from brush strokes generated,
animated and composited by Python - no image assets, no 3-D renderer, no AI image model.

* [`berceuse/`](berceuse/README.md) - *Berceuse*: one continuous take through a year on a river
  (2 min 51 s, 1080p), with a real perspective camera moving through a world of strokes.
