# 雨の路地 · Rainroji

阴雨天的日式住宅街，做成一张可以自由走进去看的「三渲二」动画背景。
灰蓝厚云、湿润反光的路面、电线与电线杆、坡道与石垣、自动售货机的冷白光、踏切与偶尔驶过的电车，全部实时渲染。

两个版本：

| 版本 | 文件 | 声音 |
|---|---|---|
| 单文件 | [`rainroji-single.html`](rainroji-single.html) | 全部用 Web Audio 实时合成：雨声层、檐下滴水、排水沟水流、售货机嗡鸣、踏切铃声、电车、原创电钢琴小曲 |
| 多文件静态站 | [`site/`](site/) | CC0 / 公有领域实录素材：街道雨声、屋檐滴水、排水沟、日本踏切（含电车通过）、萨蒂 Gymnopédie No.1、Gnossienne No.1 钢琴录音（见 [`site/audio/CREDITS.md`](site/audio/CREDITS.md)） |

声音默认关闭，右下角的小喇叭按钮开启（浏览器要求用户交互后才能播放）。

## 打开方式

- 单文件版：直接双击 `rainroji-single.html`。
- 多文件版：需要通过 HTTP 访问（音频用 `fetch` 加载），例如 `cd site && python3 -m http.server`，然后打开 <http://localhost:8000>。
- GitHub Pages：在仓库设置里选择 “Deploy from a branch”，分支根目录即可；根目录的 `index.html` 会跳转到 `site/`。

需要支持 WebGL2 的浏览器（近几年的 Chrome / Edge / Firefox / Safari）。

## 操作

| 电脑 | 手机 / 平板 | 效果 |
|---|---|---|
| 左键拖动 | 单指拖动 | 旋转视角 |
| 滚轮 | 双指捏合 | 缩放 |
| 右键拖动 | 双指拖动 | 平移（沿地面） |
| 双击地面 / 房子 | 双击屏幕 | 走到那里 |
| W A S D / 方向键（Shift 加速） | — | 沿地面移动 |

相机的碰撞处理（`src/camera.js`）：
- 视点（环绕中心）碰到墙会**沿墙滑动**，不会卡住或被弹回；地形、石阶、坂道上会平滑地跟随高度。
- 房子挡在视点和相机之间时，相机沿「弹簧臂」**平滑地**拉近（用一扇形射线提前感知转角，拉近/放远都有速度上限），而不是一帧之内跳到另一个位置。
- 拉远到屋顶以上时不再做遮挡处理，可以自由俯瞰。
- `node tools/camtest.mjs` / `node tools/touchtest.mjs` 用无头浏览器模拟环绕、行走、平移、缩放和触屏手势，检查相机路径有没有突变。

## 场景里有什么

- 主街（带斑马线、止まれ、L 型侧沟和格栅盖、井盖）、十字路口、窄巷、通往高台的石阶、一条爬坡的坂道、坡顶的小神社。
- 石垣（間知石）高台上的住宅区，可以俯瞰低处的屋顶和电线。
- 一户一户程序生成但参数各异的住宅：切妻 / 寄棟 / 片流れ / 平屋顶，瓦、石板、彩钢屋面，窗格、面格子、庇、雨户箱、阳台、空调外机、电表、燃气表、门柱灯、信箱、自行车、盆栽、紫阳花。
- 老式木造民家、二层木造公寓（外廊 + 钢楼梯）、公寓楼、关门的洗衣店、町工厂、月极停车场、菜地、儿童公园、空地。
- 角落的「たなか商店」和三台自动售货机、红色圆筒邮筒、カーブミラー。
- 河渠与小桥、樱花行道树、铁路（接触网、踏切栏杆会落下、警报灯交替闪烁）、定时驶过的电车。
- 远处层叠的山和输电铁塔，被雨雾逐渐吞没。

动态：持续的雨丝（屋檐下不会下雨）、落在任何表面上的水花、屋檐与阳台滴水、落水管出水、排水沟里流动的水、水洼涟漪、电线和树叶随风摆动、缓慢飘移的云和雨雾、售货机与路灯轻微闪烁、约 95 秒一班的电车。

## 渲染要点

- 所有静态几何合并进少量大缓冲，统一使用一个自定义 toon shader：柔和的分段光照、墙面/瓦片/木板/砌块/石垣等图案全部在 shader 里程序绘制，带雨渍和潮湿变暗。
- 天空可见度：从 12 个天空方向渲染一次正交深度图，得到屋檐下、窄巷、树下柔和的阴天遮蔽。
- 路面平面反射（竖向拉长的模糊，接近动画背景里的湿地面画法）+ 水洼波纹。
- 窗户使用 interior mapping，带窗帘/百叶/磨砂和少量暖色灯光的房间。
- 雨高度图用于遮挡屋檐下的雨丝，并把水花放到真实表面上。
- 自适应分辨率，保证较弱的显卡也能流畅。

## 开发

```bash
npm install
node tools/build.mjs          # dist/dev.html、rainroji-single.html、site/
node tools/shots.mjs dist/dev.html start,slope,alley   # 无头浏览器截图（dist/shots/）
python3 tools/prep_audio.py   # 重新下载并处理 site/audio/ 的素材（需要 numpy、imageio-ffmpeg）
```

源码结构：`src/main.js`（渲染循环）、`src/camera.js`（相机控制与碰撞）、`src/shaders.js`（toon 材质）、`src/render.js`（天空遮蔽、反射、后期）、`src/world/*`（街区生成）、`src/fx/*`（雨、光晕）、`src/audio/*`（两套声音）。
