# 雨の路地 · Rainroji

阴雨天里的一座日本小岛：住宅街、渔港、车站、稻田和长满杉树的山脊，做成一张可以像幽灵一样自由穿行的「三渲二」动画背景。
灰蓝厚云、湿润反光的路面、电线与电线杆、坡道与石垣、自动售货机的冷白光、踏切，和从海上雾里驶来的电车，全部实时渲染。

两个版本：

| 版本 | 文件 | 声音 |
|---|---|---|
| 单文件 | [`rainroji-single.html`](rainroji-single.html) | 全部用 Web Audio 实时合成：雨声层、檐下滴水、排水沟水流、售货机嗡鸣、踏切铃声、电车、原创电钢琴小曲 |
| 多文件静态站 | [`site/`](site/) | CC0 / 公有领域实录素材：街道雨声、屋檐滴水、排水沟、日本踏切（含电车通过）、萨蒂 Gymnopédie No.1、Gnossienne No.1 钢琴录音（见 [`site/audio/CREDITS.md`](site/audio/CREDITS.md)） |

声音默认关闭，右下角的小喇叭按钮开启（浏览器要求用户交互后才能播放）。

## 打开方式

- 单文件版：直接双击 `rainroji-single.html`。
- 多文件版：需要通过 HTTP 访问（音频用 `fetch` 加载），例如 `cd site && python3 -m http.server`，然后打开 <http://localhost:8000>。
- GitHub Pages：在仓库设置里选择 “Deploy from a branch”，分支根目录即可；根目录的 `index.html` 会跳转到 `site/`。

需要支持 WebGL2 的浏览器（近几年的 Chrome / Edge / Firefox / Safari）。

## 操作

你就是镜头：像幽灵一样在岛上任意飞行、穿行，只有房子挡得住你（碰到会沿着墙面滑开）。

| 电脑 | 手机 / 平板 | 效果 |
|---|---|---|
| 左键拖动 | 单指拖动 | 环顾（带惯性） |
| W A S D / 方向键 | 左下角摇杆 | 朝视线方向飞行（抬头就往上飞） |
| E / 空格，Q / C | — | 上升、下降 |
| Shift | — | 加速（离地越高飞得越快） |
| 滚轮 | 双指捏合 | 向前 / 向后 |
| 右键拖动 | 双指拖动 | 平移（抓住画面拖动） |
| 双击 | 双击屏幕 | 滑行到点击的位置 |

镜头只随你的输入移动，没有任何自动的“弹簧臂”或回弹，所以不会突然切换画面。
碰撞：房屋、屋顶、石垣高台、站台、海堤等注册为实体（`ctx.solid`），镜头是半径 0.35 m 的球，每 0.2 m 分步推出；地面、运河水面、海面托住镜头。
`node tools/camtest.mjs` / `node tools/touchtest.mjs` 用无头浏览器模拟飞行、撞墙、潜入运河桥下、滚轮、平移、双击滑行和各种触屏手势，检查镜头有没有跳变或穿进房子。

## 场景里有什么

一座完整的小岛，四周都是海，远处是雾中一层层的群岛：

- **住宅街**：主街（斑马线、止まれ、L 型侧沟、井盖）、十字路口、窄巷、通往石垣高台的石阶、爬坡的坂道和坡顶小神社。一户一户参数各异的住宅：切妻 / 寄棟 / 片流れ / 平屋顶，窗格、面格子、庇、雨户箱、阳台、空调外机、电表、门柱灯、信箱、自行车、盆栽、紫阳花；老式木造民家、木造公寓、公寓楼、町工厂、月极停车场、儿童公园。
- **能看进去的店**：玻璃是透明的（带雨珠和流下的雨水），里面是真的店——「たなか商店」有货架和商品、饮料冷柜、收银台、杂志架；喫茶「しぐれ」有吊灯、吧台高脚凳、小圆桌；理发店有理发椅、镜子、洗头台和转动的三色灯柱；面包房的层架上摆着面包；投币洗衣店的滚筒在转；居酒屋门口挂着红灯笼和会被风吹动的暖帘。
- **渔港**：码头、系船柱、防波堤和消波块，一红一白两座会闪烁的灯塔，随波起伏的渔船，鱼市场、渔协、船屋。
- **车站与铁路**：两侧站台的小站「雨ノ浦」（候车室、站名牌、站台灯、自行车棚），踏切；铁路一头钻进山脊的隧道，一头上了跨海长桥伸进雾里。
- **岛的其他部分**：运河从山脚的暗渠流出、经过水门入海；东边的稻田（水田里映着雨点）；石垣高台下的沙滩和黑松林、拖上岸的小船、晒网架、海中礁石上的小鸟居；西边长满杉树和阔叶林、临海是悬崖和乱石的山脊。

**动态**：持续的雨丝（屋檐下不会下雨）、落在任何表面上的水花、屋檐与阳台滴水、排水沟流水、水洼与海面上的雨点涟漪；电车按时刻表运行（从海上的雾里驶来、放下踏切、进站停车、再开进隧道，反方向亦然）；一辆小车在街上绕一圈、在港边停一会儿再开走；远海上一条亮着灯的渔船缓缓驶过；海鸥在港口上空盘旋；渔船随波起伏；灯塔闪光；电线、树叶、暖帘随风摆动；云和雨雾缓慢飘移。

声音也跟着岛走：靠近海边能听到浪一阵阵拍上来，电车停站时只剩低低的声音，开起来才有轰鸣和轨道接缝声。

## 渲染要点

- 所有静态几何合并进少量大缓冲，统一使用一个自定义 toon shader：柔和的分段光照、墙面/瓦片/木板/砌块/石垣等图案全部在 shader 里程序绘制，带雨渍和潮湿变暗。
- 天空可见度：从 12 个天空方向渲染一次正交深度图，得到屋檐下、窄巷、树下柔和的阴天遮蔽。
- 路面平面反射（竖向拉长的模糊，接近动画背景里的湿地面画法）+ 水洼波纹。
- 住宅窗户使用 interior mapping（带窗帘/百叶/磨砂和少量暖色灯光的房间）；商店则是真实的室内几何，前面是半透明、会反射天空、带雨痕的玻璃。
- 雾是贴地的：沿视线对指数高度层积分，所以街道雾气重，飞高以后能看清整座岛。
- 雨高度图用于遮挡屋檐下的雨丝，并把水花放到真实表面上。
- 自适应分辨率，保证较弱的显卡也能流畅。

## 开发

```bash
npm install
node tools/build.mjs          # dist/dev.html、rainroji-single.html、site/
node tools/shots.mjs dist/dev.html start,harbour,station   # 按预设视角截图（dist/shots/）
node tools/shotat.mjs dist/dev.html out 960 540 'name:x,y,z:tx,ty,tz[:t]'   # 任意位置/时间截图
node tools/camtest.mjs && node tools/touchtest.mjs            # 镜头与触屏测试
# dist/dev.html?stats&audit：打印顶点数，并检查道具之间、道具与房子之间、地块之间有没有重叠
python3 tools/prep_audio.py   # 重新下载并处理 site/audio/ 的素材（需要 numpy、imageio-ffmpeg）
```

源码结构：`src/main.js`（渲染循环）、`src/camera.js`（幽灵镜头）、`src/shaders.js`（toon / 玻璃材质）、`src/render.js`（天空遮蔽、反射、后期）、`src/world/*`（岛的生成：`layout.js` 海岸线与道路，`terrain.js` 地形/海/树林，`coast.js` 海堤/港口/船，`rail.js` 铁路/车站/隧道/跨海桥，`shops.js` 店铺室内，`fields.js` 稻田/沙滩，`movers.js` 车、船、海鸥）、`src/fx/*`（雨、光晕）、`src/audio/*`（两套声音）。
