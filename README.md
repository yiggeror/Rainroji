# 傍晚 · 雨窗

一个永远停在傍晚的旧房间，窗外下着雨。

**直接用浏览器打开 `index.html` 即可**（桌面和手机都可以）。单文件，不加载任何外部资源。所有几何、纹理和声音都是程序生成的。

## 怎么玩

- **台灯**：轻触可开关。灯丝有热惯性，开灯约 0.12 s 亮起，关灯冷却更慢，色温随之变红。关灯后眼睛会慢慢适应黑暗，房间里只剩窗外的冷光。
- **玻璃**：手指或鼠标划过，可以擦掉内侧的冷凝雾，笔画边缘会留下一圈被推开的水。之后雾气会一点一点重新长回来。
- **视角**：鼠标移动或在玻璃以外拖动可以小幅改变视角；手机上倾斜即可（iOS 会请求陀螺仪权限）。
- **声音**：第一次交互后开始，音量跟随雨势。
- **右下角的水滴按钮**：
  - 视角（窗内／窗外）、季节、时刻、时间流逝；
  - 雨势（冬天是雪势）、时间流速、声音开关。
  - 闲置时自动隐去。
- **窗外**：轻触亮着的窗户可以开关屋里的台灯；拖动可以挪一挪站的位置。
- **快捷键**：
  - `V` 窗内／窗外，`S` 换季节，`T` 时间流逝开关；
  - `H` 隐藏 UI，`L` 开关台灯，`M` 静音。

- **房间**：
  - 窗边：漆皮剥落的老式绿漆木窗、旧书桌、布罩台灯。
  - 书桌上：
    - 压着一块台板玻璃，玻璃下压着一张褐色老照片、一张褪成品红色的湖边合影、一张一寸照、一张撕掉一角的公交车票、一片压平的银杏叶；
    - 玻璃面像镜子一样映出台灯、杯子和墙，切口泛着绿；
    - 搪瓷杯里的茶还冒着热气，水面漂着几片茶叶，杯壁有茶渍线；
    - 一叠旧书、写了一页半的练习本和钢笔；
    - 拉出天线的半导体收音机，表盘透着暖光；
    - 印着牡丹的铁皮暖水瓶。
  - 墙上：
    - 停在傍晚六点半多的挂钟；
    - 侧墙上下角卷起的挂历，周围一圈多年前那本更大挂历留下的未褪色印子；
    - 用线卡钉在墙上的老明线，接到一个发黄的胶木插座，台灯插在上面；
    - 窗洞左下角一道细裂缝，桌面上方的墙上有手蹭出的污渍，还有几个老钉眼和锈迹。

  - 窗户：
    - 下层两格玻璃的上角，贴着褪色的红纸角花，右边那张缺了一角，用发黄的胶带粘着；
    - 窗框漆面上看得见刷痕和一道流挂；
    - 玻璃内侧有搭扣附近的手印油渍和灰尘点。
  - 灯罩：上方有多年烤出的焦黄。窗户另一侧是花窗帘，墙上贴着褪色的墙纸。
- **窗外**：
  - 对街：一排二三层的旧铺面，楼上的窗灯偶尔开、偶尔关；招牌、霓虹灯管、药店的绿十字、灯笼、红绿灯、钠灯。
  - 远处：高楼的灯火和闪烁的航空障碍灯。
  - 近处：窗边一棵梧桐的树冠在风里轻轻晃动。
  - 来往的：打伞走过的行人（伞有黑、红、蓝、黄，还有透光的透明伞），偶尔驶过的车和亮着车厢灯的老公交。
  - 雨与路面：背光才看得见的落雨，以及倒映着这一切的湿路面。
- **四季**（默认取本地日期的季节）：
  - **降水**：春天细雨、雾珠重；夏天雷阵雨，偶有闪电，雷声按距离延迟；秋天风一阵一阵；冬天下雪，雪花落在玻璃上，过一会儿化成水。
  - **梧桐**：春天新叶嫩绿，夏天浓密，秋天金黄、叶子飘落、几片湿叶贴在玻璃上，冬天只剩枝桠，枝上积雪。
  - **玻璃**：冬天内侧下角结冰花，冷凝雾更重。
  - **窗台和桌上**：春天汽水瓶里插一枝桃花；夏天一盘蚊香冒着细烟，桌上一把蒲扇；秋天两只柿子；冬天一只红色热水袋。
  - **挂历的画**：春天牡丹，夏天荷塘，秋天湖山，冬天雪村。
  - **声音**：雪几乎无声，秋天有风声和窗缝的口哨声，春夏的黎明有鸟叫。
- **昼夜**：
  - 太阳高度按北纬 31° 计算，夏天 19:30 才到傍晚，冬天 17:20 天就黑了。
  - 阴雨天的天光、窗光、路灯（高压钠灯有预热过程）都随时刻变化。
  - 对街的窗灯一盏一盏亮起和熄灭，商铺按各自的时间开门和拉下卷帘，车流和行人早晚高峰多、深夜几乎没有。
  - 墙上的挂钟显示场景时间：时间静止时它就停着。
- **窗外视角**：
  - 站在楼下的人行道上，抬头看这扇窗。外墙是褪色的赭黄石灰墙，墙皮剥落处露出砖，窗台角挂着雨水冲出的污痕。
  - 墙上有：
    - 一只旧空调外机、铸铁落水管、两根沿墙垂着的黑电线；
    - 蓝色搪瓷门牌，一张撕了一半的通知；
    - 墙角的半地下室铁栅窗，楼上的窗。
  - 墙上一盏搪瓷罩的巷灯，照亮墙面和雨丝，四周有雨雾里的光晕。
  - 街对面的钠灯穿过梧桐，把晃动的树影投在墙上。冬天只剩枝桠的影子。
  - **透过玻璃看到的房间就是那个房间**：同一个 SDF、同一盏台灯。
    - 冷凝雾从外面看是一片被台灯照亮的暖光。
    - 窗花是背光的红纸。
    - 玻璃上映着巷灯，外侧的雨滴各自倒映出一个小小的、倒置的房间。
    - 在里面擦掉的雾，出去以后还能看到那道擦痕。
  - 手机竖屏时站得更远、镜头更广，脚下水洼里能看到这扇窗的倒影，被雨点打出一圈圈涟漪。
- **每次打开都不完全一样**：暖水瓶的漆色、挂历的画（湖山、海边落日、牡丹）、钟停住的那一分钟、对街楼群的高低和店铺布局都会变；雨势也会以几分钟为周期在设定值附近时大时小。

## 实现了什么

**渲染**：WebGL2，全程线性 HDR。每帧依次是：

1. 窗外·清晰：程序化街景（广角、等距柱状投影）。
2. 窗外·失焦：同一街景按屏幕视角渲染，光源画成解析 bokeh。
3. 雨滴高度场。
4. 室内 SDF raymarch：动态分辨率，逐帧亚像素抖动；台板玻璃上的倒影是再追踪一次的真实反射。
5. 室内景深，然后做时域上采样（TAAU）：画面静止时，低分辨率的 raymarch 会收敛成全分辨率的超采样画面，所以细节在高分屏上也看得清。
6. 全分辨率玻璃合成。
7. Bloom。
8. ACES、调色、sRGB、颗粒、抖动。

**雨滴（CPU，按真实毫米计算）**：

- **形状与钉扎**：每颗水滴是一个球冠，重力对抗接触角滞后造成的钉扎力（Furmidge），由此得出的临界半径约 1.7–2.8 mm。
- **滑动**：过阻尼滑动；玻璃不均匀场造成走走停停（stick-slip）和蜿蜒，并倾向沿着旧水痕走。
- **合并与拖尾**：合并时体积、质心和动量守恒。滑动时吸收沿途雾珠，尾部按概率脱落小珠。
- **新雨滴**：直径服从 Marshall–Palmer 分布，大滴撞击时溅出卫星滴。
- **大滴压扁**：超过毛细长度的大滴会被重力压扁。

**玻璃光学（逐像素）**：

- **折射成像**：视线经过平板玻璃进入水中，再在高度场法线处做 Snell 折射，采样清晰的街景。凸透镜的出射方向随位置翻转，于是自然得到缩小、倒置的像。
- **反射**：用精确的非偏振菲涅尔。全反射时看到的是室内（台灯、桌面）的解析模型，所以雨滴边缘发暗，台灯在其中形成高光。
- **外侧雾珠层**：让背景更模糊、更灰，雨滴和水痕扫过的地方会变得清晰（擦拭效应）。
- **内侧冷凝雾**：下浓上淡，边界参差，并有冷凝水流下留下的细线；它会软化透过它看到的一切，并被台灯照出暖色。

**室内光照**：

- **台灯**：被灯罩调制的点光源。上下开口全透，布面透射约 18% 且偏暖，所以墙上出现双曲线光斑。软阴影的半影由灯泡尺寸决定。
- **窗户**：Lambert 多边形公式解析求面光源辐照度，再乘一条宽半影的软阴影。
- **间接光**：虚拟点光源加 radiosity 常量，再乘 AO。
- **色温**：用 Planck 轨迹（Kim 2002）转 sRGB，再做 3900K 的 von Kries 白平衡。2700K 的灯是琥珀色，9500K 的天光是冷青色。

**窗外**：

- **街景内容**：对街的旧楼、灯窗、商铺、霓虹（灯管由多个精灵叠成，失焦后成为一条光带）、灯笼、钠灯、红绿灯，远处高楼的灯火和航空障碍灯（顶点着色器里做遮挡测试）。
- **车**：偶尔驶过，车灯离轴变暗，前后灯随朝向改变。
- **湿路面**：倒影是柔和的竖直光柱。
- **落雨**：几米外的雨只在被背后的灯照亮时才看得见，所以只在光前出现。

**世界状态（第二期）**：

- 季节和时刻是唯一的输入。天空亮度与颜色、路灯、窗灯占用率、商铺营业、车流、曝光，都在 JS 里每帧算一次，作为 uniform 传给所有着色器。
- **曝光**按已知光照解析地估计，不做 GPU 回读，只部分补偿亮度：白天窗户偏亮，夜里关灯后房间是暗的。闪电不计入曝光，所以眼睛来不及适应。

**窗外视角（第二期）**：

- **单独的 street pass**：外墙、窗台、空调、落水管、巷灯、人行道是一个小 SDF 场景。
- **透过玻璃**：射线到达我们这扇窗时，读取同一张雨滴高度场，按 Snell 定律穿过雨滴和玻璃，继续在房间的 SDF 里 raymarch，用房间自己的光照着色。
- **街景着色**：
  - 墙上的光有：阴天天光、观者身后整条街的光、巷灯（带软阴影）、穿过梧桐「卡片」的对街钠灯（树影随风晃动），以及这扇窗本身（Lambert 面光源）。
  - 水洼按菲涅尔反射墙和窗，法线叠加随机雨点激起的扩散波纹。
- **雨丝和光晕**：在 TAA 之后叠加。
  - 雨丝按深度分层，按镜头弥散圆加宽，只在被灯照亮、尤其是逆光的地方看得见。
  - 光晕是点光源在雨雾中单次散射的闭式积分。
- **按需编译**：窗外的着色器很大，只在第一次走出去时编译。切换视角时画面先暗下 0.6 s，就绪后再亮起 1.2 s，声音同时从隔着玻璃的闷声过渡到敞开的雨声。

**声音（Web Audio 实时合成）**：

- **雨幕**：隔着玻璃被低通的雨声，带阵风起伏。
- **窗台雨点**：外面窗台上的雨点。
- **玻璃上的「嗒」声**：由模拟里真实落到玻璃上的雨滴触发，响度 ∝ D^1.5，声像随落点左右移动。
- **滴水**：水从窗框流下时触发，是气泡共振上扬的「叮」声。
- **车声**：与画面同步，响度随距离、声像随位置变化，带多普勒。
- **其他**：房间底噪、台灯开关的咔哒、手指擦玻璃的声音，以及程序生成的房间混响。

**健壮性**：

- 处理 devicePixelRatio（上限 2）、窗口缩放和横竖屏切换。
- 按帧时间动态降低或恢复分辨率。
- 页面切到后台时暂停渲染并挂起声音。
- WebGL 上下文丢失后会自动恢复。
- 着色器并行编译时，用分片模拟「已经下了 2.5 分钟的雨」，页面保持响应。
- 首屏是「雨还在下」的淡入，没有黑屏。
- 没有 WebGL2 时给出温和的提示。

## 做了哪些取舍

- **雨滴放大 8 倍显示**。这是最主要的艺术取舍。物理（钉扎、临界半径、速度）都按真实毫米计算，但如果按真实尺寸显示，1 米外的雨滴只有 2–3 个像素，看不到透镜里的倒像。
- **只用 WebGL2，不做 WebGPU**。这个场景的开销全在片元着色，WebGPU 不会带来额外的画面能力。WebGL2 在手机上覆盖更广，而同时维护 WGSL 和 GLSL 两套着色器，两条路径画面不一致的风险会翻倍。所以检测链是 WebGL2，否则给出提示，不存在「依赖 WebGPU」的路径。
- **一处位置上的取舍**。房间是临街的高台一层，地面比街道高约 2.3 m：按真实几何，若在二楼坐在窗边，是看不到街面车流的。
- **窗外是方向参数化的远景**，bokeh 是能量守恒的解析圆盘，而不是散射式景深。好处是便宜、可控、在手机上稳定。
- **间接光是近似**（虚拟点光源 + 常量 + AO），不是真正的全局光照。
- **雾珠不逐颗模拟**：用 0.5 mm 网格上的连续密度场表示，渲染时再程序化地还原成小水珠。
- **景深焦点在玻璃上**，所以离玻璃 30 cm 的台灯和杯子会略虚。这是照片上该有的样子，但近处细节因此不如玻璃上锐利。
- **窗外的树冠在画面上方之外**：梧桐的树冠在二楼高度，站在楼下看窗时它在头顶，所以窗外视角里只看得到它投在墙上的影子。
- **窗外视角里，房间的热气和挂钟这些细节**在玻璃和雾后面几乎看不见。所以从外面看时，房间只算光照，不算热气的体积散射；蚊香的烟例外，它紧贴着窗。

## 还可以继续提升

- **真机性能**：本次只在无头 Chromium + SwiftShader（软件渲染）里验证了正确性和画面，没有测过真机帧率。动态分辨率会自动适配，但中低端手机上的室内 raymarch 仍可能偏重。可以把静态的阴影和 AO 预烘焙进 3D 纹理，每像素只剩一次查表。
- **声音**：在浏览器里验证过音频图能运行、电平合理、没有削波，但我无法亲耳试听，音色和平衡值得再用耳朵调一遍。
- **雨水投影**：窗外一盏小而远的路灯，可以把玻璃上的雨滴投成在墙上缓慢流动的光斑（雨窗影子）。现在的几何下光线进不到可见的墙面，所以没有做。
- **内侧水珠**：内侧冷凝水目前是连续的雾场。可以让它在擦拭边缘凝成小水珠并流下。
- **更多变化**：季节、昼夜和窗外已经做了。还可以做不同的房间布置，或让雨偶尔停下、玻璃慢慢干掉。
- **窗外的水洼倒影是近似的**：它只「看见」一面平墙和窗的平均亮度，不重新追踪墙上的凸出物。从窗外看进房间时，房间是完整着色的，所以手机上这一块比室内视角更重。
- **TAAU 的代价**：视角快速移动时，前一两帧的细节会略软，之后重新收敛。
- **近景的清晰度**：书桌前沿的物件（本子、收音机）离镜头近、在景深外，凑近看是虚的。这符合「焦点在玻璃上」的设定，代价是这些细节只能远看。
- **WebGPU 计算**：可以用 WebGPU 计算着色器把雨滴模拟搬到 GPU，支持上万颗雨滴，并把 GLSL 后端保留作为回退。
