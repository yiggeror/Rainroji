# 一粒光

一部动画短片。雨夜的房间里，你去点台灯，灯没有关上，而是从灯丝里蹦出一粒光。它在屋里飘了一圈，钻进窗上的一颗雨滴，然后穿过七种画法完全不同的世界，最后从一杯茶里浮上来，回到台灯里，灯重新亮起。

它有两种看法：

- **成片**：约 2 分钟的视频，带配乐。由 `?film` 模式逐帧录制（见下面「录成片」）。
- **互动版**：直接在浏览器里打开，可以用手牵着那粒光；不碰也能自己播完，每个世界停留得更久一些。

## 怎么打开（互动版）

- 直接双击 `index.html`，用桌面版的 Chrome、Edge、Firefox 或 Safari 打开。不需要服务器，也不需要联网。
- 想发给别人，用 `yiliguang-single.html`：它是同一部片子合成的单个文件。在仓库根目录运行 `node yiliguang/tools/inline.mjs` 可以重新生成。
- 声音要在你第一次点或按屏幕之后才会开始，这是浏览器的规定。建议戴耳机。
- `index.html?film`：在浏览器里看成片的剪辑（节奏和成片一样，但声音是实时的，没有配乐）。

## 十种画法，一条光的旅程

每一种画法里，那粒光都是「光被画出来的方式」本身。

| | 世界 | 画法 | 光在这里是什么 | 通往下一个世界 |
|---|---|---|---|---|
| 1 | **雨夜·房间** | 写实的光线追踪：雨滴、玻璃、雾气、台灯 | 从灯丝里逃出来的一点暖，一个真的会移动的光源 | 窗上每颗雨滴里，窗外的街正在被一笔笔画出来；扎进它所在的那一颗 |
| 2 | **孔特笔·雨夜的街** | 修拉那样的炭精笔素描：没有轮廓线，只有炭粉挂在纸的颗粒上。街、河、桥是一张生成的长图；路灯、树、河岸上的人，和一套逐帧画出来的动画（打伞走路的男人和孩子、拄手杖的绅士、小跑的马和出租马车、追光的小狗、鸽子、驳船）在一张图集里，按远近有视差。一阵阵风吹斜雨丝、溅起水花、吹歪炊烟；画面每秒八张地「重画」，右边还没画到的地方一笔笔画上去 | 纸的白：它到哪里，哪里的炭粉就退开 | 它越来越亮，把整张画擦成白纸；夏天从白里出来 |
| 3 | **盛夏·午后** | 手绘动画背景：厚涂的积云、赛璐璐的草原；燕子、蝴蝶、蜻蜓、种子、云影 | 风里的一点阳光 | 风卷来一张纸，落在草尖上；纸上只印着墨版——一个雪夜村子的黑线，还没上色。光飞到它上面停一停（暖光落在纸上），然后直落下去、穿进纸面：纸面把它切开，穿过去的那一半已经是版画里的火苗。颜色从那一点一圈圈印开；镜头降下来、转正，直到纸就是整个画面——纸上的本来就是那个村子 |
| 4 | **雪夜·戏台** | 新版画（套色木刻）：一个真的三维村子，用光线求交画出来，再「印」——面一变就是墨版的线，色版错位，天上有木纹，和纸纤维，胡粉落雪 | 落进纸里的那粒光，成了版画里一朵刻出来的火苗 | 它顺着巷子飞，一路点亮横过巷子的灯笼串，越过等着看戏的全村人，钻进村口戏台的那块幕；幕从那一点亮起来。镜头跟着推进幕里，直到幕就是整个画面——幕上的本来就是皮影那个世界 |
| 5 | **戏台·皮影** | 幕后点着油灯，每一片皮影（生成的雕花染色牛皮）从灯的位置逐像素投到幕上：贴着幕的清楚，离幕远的大而虚；灯一晃，远处的影子跟着挪，灯烟的淡影飘过，艺人手里的竹签投下细影。九节的龙追珠，武将骑马出城门、过石桥，兵士举旗反向跑，渔翁在船上晃，鲤鱼跃起，鹤扇着翅膀飞过 | 幕后那盏灯；它在幕上的那团亮，就是龙要追的珠 | 珠往下一沉，落进皮影的浪里——浪线以下就是海：两个世界每一帧都在画，镜头跟着珠往下走，上面的幕慢慢退出画面 |
| 6 | **海·透明水彩** | 颜料是乘上去的（一层层罩染）：湿画法的大片水色、干后的硬边和深线、水渍、撒盐、颗粒；纸白就是光 | 珠：画面里唯一的暖色，四周的颜料被提掉、留出纸白 | 一头座头鲸游过来，停在珠旁边看它、眨眼；一只鱿鱼受惊喷出几团墨，墨在水里翻卷成烟，越来越浓，颜色被它吃掉——只剩墨 |
| 7 | **水墨·烟雨长卷** | 一幅三屏长的宋元笔意手卷（生成的图，照程序画的构图重画）：主峰、两叠瀑布、雨竹、石桥和它的倒影、树丛里的村子、亭子、芦苇、渔舟、雁。它在眼前画出来：每一处什么时候画事先算好（`tools/ink_times.py`）——淡墨在湿纸上一团团洇开，顺着纸纤维渗出毛边，干了往回收、留一圈水渍线，有的地方回渗开花；笔线先是湿的、软的，渗进纸里才收紧；最浓的点最后落。比纸更近的松枝、垂柳、芦苇滑过得更快，也在风里摆；细雨在河面打出一圈圈涟漪，渔舟拖着尾波，鲤鱼跃起，燕子掠过 | 一点朱砂，也是画笔：它走到哪里，那里的每一笔才顺着笔势画出来 | 天亮时它留在渔舟上当船灯，分出一粒火星升上天，成了太阳；颜色从太阳那里一圈圈炸开 |
| 8 | **印象派·清晨睡莲池** | 一万多笔有方向、有厚度的笔触，色彩碎片，补色并置；涟漪、阵风、蜻蜓、青蛙、晨雾 | 初升的太阳，和水面上的第一点光：它经过的睡莲一朵朵张开 | 池子开始变成一张画：睡莲叶成了平涂的绿椭圆，柳条成了绿弧 |
| 9 | **康定斯基·点线面** | 全部是代码画的形状，边缘有手绘的抖，颜色里有刷痕，底下是布纹；每样东西一个个出现，各自发一个音，然后慢慢呼吸（不踩任何节拍，换什么配乐都不会和它打架），几个小圆慢慢绕着走 | 那个「点」：线一根根从它射出去 | 镜头推进蓝圆，一块蓝咬掉黄圆的一边，成了一弯月亮；月牙长成下一个世界那弯纸板月亮的轮廓，颜料变成纸板 |
| 10 | **定格动画·纸船远航** | 桌上搭的一台小布景（生成的图层）：卡纸天幕、瓦楞纸月亮、吊线的棉花云和锡箔星、三条像戏台浪机一样转过去的玻璃纸浪；纸船从左边驶进来，骑在浪上起伏，船头扎下去溅起棉花浪花；毛毡小孩是一个拆开的定格木偶（身体、两段胳膊、替换的手和头、风里翻飞的围巾），每秒 12 格地摆：护着光看浪、抓紧船沿、被浪花溅得皱脸、甩头大笑、把光托向前方、回头看海鸥、把光举给它、弓身护光、跪起来把光举高、挥手送它，一路不重复；一只海鸥吊在线上跟上来，在光上面盘旋 | 小孩手里捧着的那粒光：浪上有它的一道碎金倒影，玻璃纸的褶跟着它闪，海鸥、浪花、帆被它照暖 | 小孩跪起来把光高高举起，光离开他的手，朝镜头飘来，他挥手送它，白——是书桌上那杯茶 |
| ↩ | **回到房间** | 同一个雨夜 | 回家的光 | 它飞回台灯，灯重新亮起 |

光是一条线，镜头从头到尾不切：下一个世界一直就在这个世界里面——草上那张纸印着村子，村口戏台的幕上演着皮影，皮影的浪下面是海——光钻进去，那个世界就从它进去的地方醒过来。转场时两个世界每一帧都在画，交界是画面里一个真的东西（纸面、幕、浪线、墨团的边）。

画风彼此不撞：木刻是冷蓝雪夜里刀刻的硬线和平涂；水墨是暖灰烟雨里湿的、洇开的笔，没有一根硬线，两者在片中隔着两个世界。皮影是「光穿过来」，木刻是「印在纸上」。印象派是全片颜色最饱和、最碎的一个，紧接在全片颜色最少的水墨之后。

## 做法要点

- **以房间为宿主。** `src/room.js` 是原来的雨窗，它拥有 WebGL 上下文、渲染循环、动态分辨率、上下文丢失后的恢复和声音。其他世界注册到 `YL.worlds`，共用它的 GL 上下文。所以不需要打包工具，双击就能打开。
- **导演**（`src/director.js`）是一个状态机：决定这一帧画哪个世界；转场时同时画两个世界，在合成着色器里交接；让光在两边的屏幕位置保持一致。`?film` 时换成成片的节奏，并且替观众「动手」：夏天里一阵风扫过草地、按住不动让风停下；深海里小鱼一齐受惊——因为鲸来了。
- **每个世界都用自己的画法画这粒光，也用这粒光照亮自己。** 它的明暗呼吸节奏在所有世界里都一样；它还有一个三音动机，每个世界换一种音色。
- 每个世界的做法、试过又放弃的东西、每一轮自评和修改，都记在 [`DEVLOG.md`](DEVLOG.md)，配有截图。

## 录成片

```
Q=0.5 node yiliguang/tools/rec.mjs out/film.mp4 "film&seaq=0.75" 140 1280 720   # 逐帧渲染画面和环境声
node yiliguang/tools/master.mjs out/film out/一粒光.mp4 1280 720                    # 配乐、混音、响度、片名
```

- `rec.mjs` 打开 `index.html?rec&film`：片子不跟真实时间走，每帧固定 1/24 秒。声音在一个**离线音频上下文**里渲染，它在每一帧的边界停下：先推进整部片子一帧、画出来、存下，声音才往前渲染这一帧。所以雨声、蝉声、木轮声、深海的嗡鸣、古琴、鸟叫和画面严格对齐，与机器快慢无关。画面直接以 PNG 流进 ffmpeg 编码。
- `master.mjs` 把配乐垫在环境声上（配乐从光跳出台灯那一刻进来），整体响度归一到约 −16 LUFS，片尾加片名和署名。配乐和字体第一次使用时自动下载。
- `Q` 是房间光线追踪的内部分辨率（1 = 满分辨率），`seaq` 是深海的内部分辨率；画面最后都按输出分辨率合成。
- **没有显卡时很慢。** 软件渲染（SwiftShader）下，720p 一帧：房间约 5.5 秒（`Q=0.5`），深海加鲸约 9 秒，其他世界一到几秒；整部片子约三小时。1080p 要两倍多。有显卡的机器上会快得多。
- 画面是在页面里直接从画布读出来的（画布保留了绘制缓冲），而不是截整个页面：1080p 的软件渲染画布，截图常常超过浏览器肯等的时间。
- **只重画改过的一段。** 房间的开头和回家的结尾最慢（软件渲染下各约一个半小时），中间的世界改了，它们不用重画：
  ```
  node yiliguang/tools/rec.mjs new/film.mp4 "film&draw=290-&drawTill=surface" 160 1280 720 16   # 整部片子照样从头跑，只画 290 帧起、到回家开始为止
  python3 yiliguang/tools/splice.py old/film new/film out/film --from 290                          # 接进上一次的整片
  ```
  没画的帧照样推进故事、模拟和声音，只是画得极小、不交出来，所以新的声音是完整的一条。`splice.py` 先核对新画面的头几帧和旧画面同一位置的帧一样，再在旧画面里找到新画面最后一帧（回家开始的那一帧，此刻画面是白的），从它的下一帧接着用旧的；中间的世界变长变短都接得上。不加 `drawTill` 就一直画到片尾，`splice.py` 加 `--to-end`，只用旧的开头。

## 配乐与字体

- 配乐：**"The Parting"**，Kevin MacLeod（[incompetech.com](https://incompetech.com)），[Creative Commons: By Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)。片尾有署名。
- 片名字体：Noto Serif SC（思源宋体），SIL Open Font License 1.1。
- 这首曲子比片子略长。没有任何一段重复：只在它安静的前半里略去一段（52.03 秒到 83.51 秒）。这两处之前 4 秒、之后 2 秒的和声和响度几乎一样（逐帧比较音级找出来的），接上听不出来，0.34 秒的等功率交叉淡化盖住接缝。这样放，它的高涨落在睡莲池、康定斯基和纸船远航上，豁然展开的那一段落在光离开孩子的手、飞向镜头时，最后的终止落在台灯重新亮起和片名上。`tools/master.mjs` 自己做这一步。
- 片中其余所有声音（雨、蝉、风、木琴、深海、鲸、古琴、二胡、锣、鸟、水滴、炭笔、玻璃纸）都是程序实时合成的。
- 孔特笔、定格动画两个世界的图层是用图像模型生成的（提示词在 `assets/prompts/`），由 `tools/pack_assets.py` 裁切、压缩后放进页面；康定斯基那一段只用生成的定帧做构图参考，画面全是代码画的。
- 前面几个世界也用了生成的图来补细节（同样由代码让它们动）：夏天的天空和远景（云会飘、会翻，樟树在风里摆，云影扫过远坡）、睡莲池笔触取色用的那张印象派底画、雪夜村子背后的新版画夜空和雪山、走马灯里的皮影布景和龙；纸、和纸、宣纸、亚麻布的纹理也是生成的扫描。

## 已知的不足

- **截图和成片都来自软件渲染（SwiftShader）。** 在真显卡上互动版会流畅得多；手机上没有在真机上测过。
- **声音只验证了技术层面**：音频图能跑、电平合理、不削波、和画面逐帧对齐。音色和混音的好坏需要用耳朵听。
- 系统设置了「减少动态效果」时，木刻的线条、印象派的笔触不再在每一印之间抖动。
