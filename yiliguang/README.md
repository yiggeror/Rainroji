# 一粒光

一部可以互动的动画短片，约三分半钟，不碰也能自己播完。

雨夜的房间里，你去点台灯，灯没有关上，而是从灯丝里蹦出一粒光。它在屋里飘了一圈，钻进窗上的一颗雨滴，然后穿过几个完全不同的世界：一个盛夏午后的手绘动画、一张雪夜的套色木刻、一片漆黑的深海。最后它从一杯茶的水面浮上来，回到台灯里，灯重新亮起。

## 怎么打开

- 直接双击 `index.html`，用桌面版的 Chrome、Edge、Firefox 或 Safari 打开。不需要服务器，也不需要联网。
- 想发给别人，用 `yiliguang-single.html`：它是同一部片子合成的单个文件。在仓库根目录运行 `node yiliguang/tools/inline.mjs` 可以重新生成。
- 声音要在你第一次点或按屏幕之后才会开始，这是浏览器的规定。建议戴耳机。
- 手机竖屏也可以看，每个世界都为竖屏单独取过景。

## 做法要点

- **以房间为宿主。** `src/room.js` 是原来的雨窗，它拥有 WebGL 上下文、渲染循环、动态分辨率、上下文丢失后的恢复和声音。其他世界是普通脚本，注册到 `YL.worlds`，共用它的 GL 上下文和工具函数。所以不需要打包工具，双击就能打开。
- **导演**（`src/director.js`）是一个状态机：
  - 决定这一帧画哪个世界；
  - 转场时同时画两个世界，在一个合成着色器里交接；
  - 让光在两边的屏幕位置保持一致。
- **每个世界都用自己的画法画这粒光，也用这粒光照亮自己**：
  - 房间里，它是光线追踪的点光源，有软阴影；
  - 夏天里，它是赛璐璐的硬边光块，照亮周围的草；
  - 木刻里，它是一团小火苗，光是刻掉的白线；
  - 深海里，它是水中散射的光晕，只有它照到的地方才可见。

  它的明暗呼吸节奏在所有世界里都一样。它还有一个三音动机，每个世界换一种音色：房间里是钢片琴，木刻里是木琴。
- 每个世界的做法、试过又放弃的东西、每一轮自评和修改，都记在 [`DEVLOG.md`](DEVLOG.md)，配有截图。

## 调试参数（加在地址后面）

| 参数 | 作用 |
|---|---|
| `?phase=名字&pt=秒` | 直接跳到某一段：`wander` `window` `daydrops` `dive` `summer` `updraft` `cloud` `print` `woodcut` `leave` `tear` `deepsea` `rise` `surface` |
| `?world=summer` `woodcut` `deepsea` | 只看一个世界，不放主角 |
| `&wt=秒` | 世界的起始时间 |
| `&still` | 关掉镜头漂移（截图用） |
| `&fast=k` | 整部片子快 k 倍（测试用） |
| `&shot&frames=N` | 截图模式：画 N 帧后停下 |
| 木刻：`&wh=x,y`、`&shiver=秒` | 把火苗放在版画某点；看灯笼抖雪 |
| 深海：`&calm=秒`、`&scare=秒`、`&lure=米`、`&whale=x` | 小鱼靠近与受惊；灯笼鱼；鲸（未完成） |

## 已知的不足

- **鲸还没做好，没有放进片子。** 计划里有「一头鲸从光照的边缘经过」，代码已经写了两版，但皮肤和眼睛还不够真，按「宁缺毋滥」先拿掉了。`&whale=x` 可以看到现在的样子。
- **截图都来自软件渲染（SwiftShader）。** 在真显卡上会更流畅；手机上没有在真机上测过。
- **声音只验证了技术层面**：音频图能跑、电平合理、不削波。音色和混音需要用耳朵听。
- 系统设置了「减少动态效果」时，木刻的线条不再在每一印之间抖动。
