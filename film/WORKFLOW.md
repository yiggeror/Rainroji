# 像素氛围短片：制作流程与思路

写给之后要做同类短片的 agent。这支片子是五个「可无缝循环的像素动态场景」拼成的 2 分 18 秒短片，
全部画面由本目录的代码渲染，没有任何图片素材。下面按实际走过的顺序写，重点是**哪些判断决定了成败**，
以及走过的弯路。

---

## 0. 先把参考片拆开看（不要凭印象）

拿到参考视频后先做量化分析，再谈风格：

| 看什么 | 怎么看 | 这次得到的结论 |
|---|---|---|
| 循环长度 | 降采样后逐帧和第 0 帧求差，找差值极小的帧 | 5 秒一循环；整段视频只是它重复很多遍 |
| 原生像素网格 | 截帧放大看像素块 | 约 240×140，放大 4 倍；色板有限、带抖动颗粒 |
| 什么在动 | 时间方向求方差图 | 只有雪、灯、极少的小元素在动，画面主体是静止的 |
| 构图 | 看截图 | **高处远眺的环境全景**，没有主角物体；建筑、树、天气层层叠叠 |
| 光 | 看截图 | 蓝调时刻的冷色环境光 + 唯一一盏暖色钠灯 |
| 音乐 | librosa：频谱质心、色度、调音偏差 | 极暗（质心约 400 Hz）、每 4 秒一个和弦、整体降调约 0.4 个半音（磁带降速感） |

结论先于技术：这类片子是「一张有纵深的静止画 + 少量周期运动 + 氛围光」，所以**90% 的精力应该花在那张静止画上**。

## 1. 技术路线

图像模型接口当时没有余额，所以走了纯代码路线，事后看它正好满足「真实空间关系」和「循环完全可控」两个要求：

```
三维场景(代码搭) ──光线追踪──▶ 分层的线性光照图(每像素 36 条光线)
        │                           │  每个可动光源一层
        │                           ▼
        │              逐帧合成：层×增益 + 粒子/烟/倒影抖动/动态物体
        │                           ▼
        └────────────▶ 调色 → 限色板 + 有序抖动 → 640×360 → 最近邻放大 3 倍 = 1080p
```

要点：

- **相机不动，所以静态画面只渲染一次**（一场 1～2 分钟），可以用很贵的算法：BVH 光线追踪、软阴影、一次漫反射反弹、
  湿地面反射、体积光。逐帧只做便宜的二维合成，一个 9 秒循环 1～8 分钟。
- **按光源分层**（`K` 个 group）：路灯、霓虹、电视窗、楼道声控灯各占一层，逐帧只改每层的增益，
  灯一闪，它照亮的雪地、墙面、水里的倒影全部跟着闪——这是「光融进环境」的关键。
- **超采样后降采样**再量化，而不是直接低分辨率渲染：细树枝、电线会变成半透明的像素，这正是参考片那种
  「照片感像素画」的质地。
- 移动的刚体（火车）不重建场景：把相机光线反向平移后去追踪火车自己的 BVH（`engine/dyn.py`），
  再用「远景层 / 近景层」两遍渲染把它夹在中间（`TWO_PASS` + `MASK_NEAR`）。

## 2. 目录

```
film/
  engine/rt.py        BVH + 光线求交 (numba)
  engine/world.py     场景搭建：quads / box / tube / extrude / sphere / grid，变换栈，光源
  engine/mats.py      程序化材质：砖、抹灰、瓷砖、沥青(干/湿/水洼)、雪、玻璃窗(含窗帘/灯光)、货架、卷帘门…
  engine/render.py    静态渲染：直接光+阴影、一次反弹、反射、雾、体积光、按几何生成的污渍；输出分层 plate
  engine/hooks.py     积雪 / 淋湿（朝上且头顶无遮挡才生效）、俯视地面贴图（小路、脚印、水域）
  engine/props.py     道具：居民楼(阳台/防盗窗/空调/开着的窗扇/晾衣杆/被子/电缆)、树、电线杆路灯、车、自行车、平房…
  engine/fx.py        逐帧效果：循环粒子(雪/雨/落叶)、烟、涟漪、鸟群、旗、树叶晃动、辉光、暗角、降噪
  engine/dyn.py       移动物体
  engine/pix.py       调色、OKLab k-means 色板、双色有序抖动
  scenes/*.py         五个场景：build()/camera()/sky()/setup()/frame(ph)
  run.py              run.py <scene> still|anim <每像素采样边长>
  audio/music.py      原创配乐（MIDI → fluidsynth → 磁带链路）
  audio/sfx.py        环境音床（CC0 实录裁成 27 秒无缝循环）
  make_film.py        总装：叠化、混音、导出 film.mp4 与 loops/*.mp4
  build.sh            从零重建
```

## 3. 场景设计：从用户反馈里学到的规则

第一轮我做错了四件事，被用户逐条指出，改完之后才对味。**这一节比任何技术细节都重要。**

1. **不要把画面聚焦在一个物体上。** 第一版的「小卖部门脸」「教学楼正面」「贴脸驶过的货车」全是这个问题：
   一旦镜头怼着一个东西，程序化模型的细节不足立刻暴露。改成**高一点、远一点的全景**（三四层楼高度，
   主体在 30～100 米外），同样的模型马上就成立了，细节以「很多很小的东西」的形式存在。
2. **不要普通的光线。** 「大白天的校园」被否了。氛围来自**过渡时刻和天气**：晨雾、雨后晚霞、雨夜、黄昏、
   蓝调雪景。每场给一个「冷的大环境 + 少量暖光点」的结构，建筑要和天气融在一起（雾吃掉远楼、
   水洼映出晚霞、雨丝只在灯光里可见）。
3. **美感优先于「有内容」。** 冷却塔+货运列车的工业场景被评价为「只有压抑没有美感」。换成山坡上远眺
   小城边缘、亮着暖窗的绿皮车滑过、池塘映着粉紫晚霞——同样是铁路，情绪完全不同。孤独要靠「安静而好看」来表达。
4. **人物宁缺毋滥。** 方块拼的人哪怕很远也僵硬。最后只在雪景留了一个很远的身影（圆润的锥形肢体、
   微微前倾、重心在一条腿），其余场景只留「有人生活过」的痕迹：亮着的窗、炊烟、晾着的被子、楼道里逐层亮起的声控灯。
5. **「干净但空」是程序化场景的通病。** 解决办法按性价比排序：
   - 把原生网格从 480×270 提到 640×360，色板从 44 色提到约 90 色（否则是大色块，像低模打马赛克）；
   - **跟着几何走的污渍**（`render.weathering`）：墙角短程遮蔽变暗；墙面向上打一条短光线，头顶有窗台/空调/
     阳台就往下流雨痕。不用手摆，脏的位置自然是对的；
   - 材质里加大尺度色差、返碱、抹灰脱落露砖、补丁、小广告；
   - 立面上的生活痕迹：开着的窗扇、窗台花盆、伸出去的晾衣杆、搭在栏杆上的被子、沿墙乱拉的电缆、
     太阳能热水器、水箱、杂物堆；
   - 地面：起伏的高度场 + 解析法线（雪地在侧光下才有形体）、压实的小路、成串的脚印、灌木、长椅、自行车。
6. **中式的识别物**要小而准：春联、福字、灯笼、横幅、山墙标语、灯箱招牌、彩条布雨棚、理发店转灯、
   「好好学习 天天向上」、绿皮车。文字用系统里的中文字体渲染成贴图贴在几何体上。

每场定稿前自查：缩略图里有没有清楚的明暗大块？有没有前/中/远三层？暖色是不是只占一小块？
有没有哪个物体大到能看清它是怎么拼的？

## 4. 无缝循环的写法

所有运动都写成相位 `ph ∈ [0,1)` 的周期函数，**不存状态**：

- 粒子（雪/雨/落叶）：每个粒子位置 = 基点 + 速度 ×（自身相位 − 0.5）× 寿命，寿命 = 周期/整数；首尾各 10%
  淡入淡出，于是粒子「跳回起点」那一下不可见。粒子在三维里，按 plate 里存的每像素深度样本做遮挡，
  并按各光源的距离平方衰减着色——雪花飘进路灯光锥会变成暖色。
- 噪声随时间变化用「两段交叉淡化」：`n(t)·(1−ph) + n(t−T)·ph`。
- 闪烁用 `hash(floor(ph·N))`；一次性事件用 `pulse(ph, t0, t1)`，保证循环末尾回到初始状态
  （例如楼道灯：五层依次亮，每层 2 秒，最后一层在循环结束前熄灭）。
- 火车：每个循环走整数节车厢，车厢序列按这个整数重复。
- 成片里每场放 3 个循环（27 秒），循环长 9 秒 = 配乐的 2 小节，切换点全部落在小节线上。

## 5. 像素化

`pix.tonemap`（曝光→肩部→对比→饱和→抬黑）之后，在 OKLab 里对若干相位的帧做 k-means 得到整场固定色板，
然后做**双色有序抖动**：每个像素取最近的两种色板色，按它在两色连线上的位置和一张固定阈值图比较。
阈值图用 Bayer 与蓝噪各半；强度 0.5。阈值图固定，所以静止区域不会闪。
量化前对静态光照层做一次联合双边降噪（以亮度、深度、反照率为引导），去掉蒙特卡洛颗粒但不动任何可见边缘。

## 6. 声音

- **配乐**没有复用参考曲（有版权），而是照它的气质原创：每小节一个和弦的毡感钢琴、五声的小旋律、
  高八度的音乐盒；随场景由疏到密再回落。处理链决定了「核」的味道：降速 2.5%（降调）、抖晃、
  1.9 kHz 低通、长混响、磁带嘶声。听不到声音的 agent 可以用 librosa 把频谱质心、调音偏差和参考曲对一下。
- **环境音**用 BigSoundBank 的 CC0 实录。每场一条 27 秒的音床：取一段，尾部 3 秒交叉淡化进头部，就能无缝循环；
  再放几个定点的一次性声音（鸽子起飞、远雷、狗叫）。整体压在配乐下面 6～10 dB，全部做了低通，听感是「隔着一段距离」。

## 7. 交付

`make_film.py`：场景间 1 秒叠化，片头淡入、片尾 3 秒淡出；混音后 `loudnorm` 到 −16 LUFS；
x264 `-crf 14 -preset slow`，最近邻放大。循环片段只带环境音不带配乐。
视频里不放片名、字幕、署名（用户要求）。

成片 142 MB，超过 GitHub 单文件 100 MB 的限制。没有创建 Release 的权限，所以没有压缩，而是在关键帧上
用流拷贝无损切成两段（`ffmpeg -c copy -f segment -segment_times 82`；GOP 设成 60 帧，所以偶数秒都是关键帧，
切点选在第三、四场的交界之后），并附 `out/join.sh` 拼回。有 Release 权限时应直接把整片传到 Release。

## 8. 踩过的坑

- 高频程序化噪声在远处会变成雪花噪点：材质里按距离淡出细节（`mats.fade`）。
- 反弹光线打到小而亮的发光面会出「萤火虫」：给它们加 `MASK_NOBOUNCE`，另放一盏显式点光源。
- 掠射角下菲涅耳会让整片湿地面变成镜子（操场看着像被淹了）：只有真正的水洼给高反射率。
- 雨丝用 alpha 混合会在亮背景上变成黑道：改成加色。
- 离相机太近的树叶/电线/草是画面杀手：镜头前十几米清空。
- 640×360×36 采样、9 个光照层时内存约 5 GB；层数再多就要分块。
- 时间：一个场景从零到能看约 30～60 分钟，其中构图和光的迭代占大半；每次试渲用 `still 3`（9 采样，十几秒）。
