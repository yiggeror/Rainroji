# 像素氛围短片：制作流程与思路

写给之后要做同类短片的 agent。这支片子是一支 lofi 电台式的短片：春夏秋冬四个「可无缝循环的像素动态场景」，2 分 27 秒，
全部画面由本目录的代码渲染，没有任何图片素材；配乐是成品的 CC0 lofi 曲。

它做了两轮。第一轮五个场景里只有两个（雪、雨）被用户认可，第二轮照着这两个成立的原因重做了春和秋。
**第 3 节是全篇最重要的部分**：记录了用户每一条否定意见和从中得到的规则。下面按实际走过的顺序写，重点是**哪些判断决定了成败**，
以及走过的弯路。

---

## 0. 先把参考片拆开看（不要凭印象）

拿到参考视频后先做量化分析，再谈风格：

| 看什么 | 怎么看 | 这次得到的结论 |
|---|---|---|
| 循环长度 | 降采样后逐帧和第 0 帧求差，找差值极小的帧 | 5 秒一循环；整段视频只是它重复很多遍 |
| 原生像素网格 | 截帧放大看像素块 | 约 240×140，放大 4 倍；色板有限、带抖动颗粒 |
| 什么在动 | 时间方向求方差图 | 只有雪、灯、极少的小元素在动，画面主体是静止的 |
| 构图 | 看截图 | **高处远眺的环境全景**，没有主角物体；建筑、树、天气层层叠叠 |
| 光 | 看截图 | 蓝调时刻的冷色环境光 + 唯一一盏暖色钠灯 |
| 音乐 | librosa：频谱质心、色度、调音偏差 | 极暗（质心约 400 Hz）、每 4 秒一个和弦、整体降调约 0.4 个半音（磁带降速感） |

结论先于技术：这类片子是「一张有纵深的静止画 + 少量周期运动 + 氛围光」，所以**90% 的精力应该花在那张静止画上**。

## 1. 技术路线

图像模型接口当时没有余额，所以走了纯代码路线，事后看它正好满足「真实空间关系」和「循环完全可控」两个要求：

```
三维场景(代码搭) ──光线追踪──▶ 分层的线性光照图(每像素 36 条光线)
        │                           │  每个可动光源一层
        │                           ▼
        │              逐帧合成：层×增益 + 粒子/烟/倒影抖动/动态物体
        │                           ▼
        └────────────▶ 调色 → 限色板 + 有序抖动 → 640×360 → 最近邻放大 3 倍 = 1080p
```

要点：

- **相机不动，所以静态画面只渲染一次**（一场 1～2 分钟），可以用很贵的算法：BVH 光线追踪、软阴影、一次漫反射反弹、
  湿地面反射、体积光。逐帧只做便宜的二维合成，一个 9 秒循环 1～8 分钟。
- **按光源分层**（`K` 个 group）：路灯、霓虹、电视窗、楼道声控灯各占一层，逐帧只改每层的增益，
  灯一闪，它照亮的雪地、墙面、水里的倒影全部跟着闪——这是「光融进环境」的关键。
- **超采样后降采样**再量化，而不是直接低分辨率渲染：细树枝、电线会变成半透明的像素，这正是参考片那种
  「照片感像素画」的质地。
- 需要有东西从近景和远景之间穿过时，可以渲染两遍（`TWO_PASS` + `MASK_NEAR`：一遍把近景物体对相机隐藏）再分层合成；
  成片最后没有用到会动的大物体（第一轮的火车场景被否了）。

## 2. 目录

```
film/
  engine/rt.py        BVH + 光线求交 (numba)
  engine/world.py     场景搭建：quads / box / tube / extrude / sphere / grid，变换栈，光源
  engine/mats.py      程序化材质：砖、抹灰、瓷砖、沥青(干/湿/水洼)、雪、玻璃窗(含窗帘/灯光)、货架、卷帘门…
  engine/render.py    静态渲染：直接光+阴影、一次反弹、反射、雾、体积光、按几何生成的污渍；输出分层 plate
  engine/hooks.py     积雪 / 淋湿（朝上且头顶无遮挡才生效）、俯视地面贴图（小路、脚印、水域）
  engine/props.py     道具：居民楼(阳台/防盗窗/空调/开着的窗扇/晾衣杆/被子/电缆)、树、电线杆路灯、车、自行车、平房…
  engine/fx.py        逐帧效果：循环粒子(雪/雨/落叶)、烟、涟漪、鸟群、旗、树叶晃动、辉光、暗角、降噪
  engine/pix.py       调色、OKLab k-means 色板、双色有序抖动
  scenes/*.py         四个场景（spring / rain / autumn / snow）：build()/camera()/sky()/setup()/frame(ph)
  run.py              run.py <scene> still|anim <每像素采样边长>
  audio/music/        成品配乐（HoliznaCC0，CC0）
  audio/sfx.py        环境音床（CC0 实录裁成 27 秒无缝循环，每场只有一层，很轻）
  make_film.py        总装：叠化、混音、导出 film.mp4 与 loops/*.mp4
  build.sh            从零重建
```

## 3. 场景设计：从用户反馈里学到的规则

### 什么样的场景成立

最后留下来的四场（雪、雨、落花、落叶）是同一个配方，构图各不相同：

1. **一个有人住的小世界**：院子、巷子、街。相机在二到四层楼的高度往里看，主体在二三十米外。
   不是开阔的大远景，也不是怼着一个物体的特写。
2. **一种看得见的、属于这个季节的东西在画面里不停地动**：雪、雨、花瓣、落叶。
   这既是季节的标志，也是动态的主体；它们是三维粒子，会被建筑挡住，飘进灯光里会被照亮。
3. **冷的大环境 + 一两处暖光**。暖光要照在那种「在动的东西」上。窗户零星亮着，其中一扇是电视的闪光。
4. **一个大的自然形体做重心**（枯树、花树、金色的树冠拱廊），但它是环境的一部分。
5. **比现实更朦胧、更绚丽**：薄雾、很宽的辉光、偏色的调色、会发一点光的花和叶（`foliage(..., glow=...)`）。
   宁可像画，不要像照片。
6. **生活痕迹**：开着的窗扇、晾衣杆、被子、电缆、自行车、石桌石凳、春联灯笼、报刊亭、标语墙、灯箱招牌。

### 被否掉的东西，和原因

| 做了什么 | 用户的评价 | 规则 |
|---|---|---|
| 把镜头怼着小卖部门脸、教学楼正面、驶过的货车 | 一聚焦，细节的缺少就暴露了 | 不聚焦单个物体；高一点、远一点 |
| 大白天的校园 | 太平常 | 光线要是过渡时刻或天气：蓝调、黄昏、夜、雨、雪 |
| 冷却塔 + 货运列车的道口 | 只有压抑，没有美感，不知道「核」在哪 | 孤独要靠安静好看来表达，不是靠工业和灰暗 |
| 方块拼的人 | 僵硬，哪怕很远 | 人物宁缺毋滥；最后全片只有雪景里一个很远的身影 |
| 干净的低模感 | 清晰但细节少，像素反而过头 | 网格 640×360、约 90 色；跟着几何走的污渍；立面和地面的生活痕迹 |
| 天台俯瞰晨雾中的楼群 | 像随手拍；没有记忆点；「晨雾」和季节是硬凑的；动态弱 | 「氛围」不等于「雾」和「远景」。要有落点，要一眼认得出季节 |
| 山坡上远眺铁路和小城 | 平、不精细、不怀旧；火车匀速慢慢开一直不断 | 同上；另外匀速不断的运动很假，要么是粒子，要么是「快速经过—间隔—再经过」 |
| 一栋教学楼立在大操场边 | 不合常理，太疏离；黄昏不够绚丽 | 布局要合常理，不合理比细节少更出戏；颜色可以比现实更绚丽 |
| 原创的钢琴配乐 | 不要原创；这是 lofi 电台视频 | 用高质量的成品曲 |
| 蛙鸣、鸟叫、雷、狗叫、明显的雨声 | 嘈杂；雨声太突出 | 音效是底色：每场一层，低通，压在音乐下面十几 dB |

每场定稿前自查：缩略图里有没有清楚的明暗大块？暖色是不是只占一小块？季节是不是一眼认得出？
有没有哪个物体大到能看清它是怎么拼的？离相机十几米内有没有树叶、电线、草（有就清掉）？
和其他几场摆在一起，色调是不是各不相同、但一看就是同一支片子？

## 4. 无缝循环的写法

所有运动都写成相位 `ph ∈ [0,1)` 的周期函数，**不存状态**：

- 粒子（雪/雨/落叶）：每个粒子位置 = 基点 + 速度 ×（自身相位 − 0.5）× 寿命，寿命 = 周期/整数；首尾各 10%
  淡入淡出，于是粒子「跳回起点」那一下不可见。粒子在三维里，按 plate 里存的每像素深度样本做遮挡，
  并按各光源的距离平方衰减着色——雪花飘进路灯光锥会变成暖色。
- 噪声随时间变化用「两段交叉淡化」：`n(t)·(1−ph) + n(t−T)·ph`。
- 闪烁用 `hash(floor(ph·N))`；一次性事件用 `pulse(ph, t0, t1)`，保证循环末尾回到初始状态
  （例如楼道灯：五层依次亮，每层 2 秒，最后一层在循环结束前熄灭）。
- 成片里每场放 4 个循环（36 秒），循环长 9 秒。

## 5. 像素化

`pix.tonemap`（曝光→肩部→对比→饱和→抬黑）之后，在 OKLab 里对若干相位的帧做 k-means 得到整场固定色板，
然后做**双色有序抖动**：每个像素取最近的两种色板色，按它在两色连线上的位置和一张固定阈值图比较。
阈值图用 Bayer 与蓝噪各半；强度 0.5。阈值图固定，所以静止区域不会闪。
量化前对静态光照层做一次联合双边降噪（以亮度、深度、反照率为引导），去掉蒙特卡洛颗粒但不动任何可见边缘。

## 6. 声音

- **配乐用成品曲，不要自己写。** 这类片子是 lofi 电台视频，音乐是主体。第一轮我照参考曲的气质用 MIDI 原创了一首，被否了。
  第二轮用的是 HoliznaCC0 的 *Lullabies For The End Of The World #1*（Free Music Archive，CC0）。
  找曲子的办法：FMA 的专辑页里每首歌的 `data-track-info` 属性带 mp3 直链；下载一批标着 Sad / Nostalgic / Dreamy 的，
  用 librosa 测速度、调性（大小调）、鼓点占比、频谱质心，挑慢、暗、小调、鼓少的。**我听不到声音**，
  所以 `audio/music/` 里留了另外三首候选，换曲只要改 `make_film.py` 里的 `MUSIC`。曲子原样使用，只调电平和结尾淡出。
  参考曲本身有版权，没有用。
- **环境音**用 BigSoundBank 的 CC0 实录，每场只有一层（雨 / 风 / 风吹树叶），低通，取一段把尾部 3 秒交叉淡化进头部
  就能无缝循环。成片里它比音乐低十几 dB；单独的循环片段里抬高 9 dB。

## 7. 交付

`make_film.py`：场景间 1 秒叠化，片头淡入、片尾 3 秒淡出；混音后 `loudnorm` 到 −16 LUFS；
x264 `-crf 14 -preset slow`，最近邻放大。循环片段只带环境音不带配乐。
四场都铺满粒子，码率约 12 Mbps，这是不压画质的代价。
视频里不放片名、字幕、署名（用户要求）。

成片 229 MB，超过 GitHub 单文件 100 MB 的限制。没有创建 Release 的权限，所以没有压缩，而是在关键帧上
用流拷贝无损切成三段（`ffmpeg -c copy -f segment -segment_times 50,98`；GOP 是 60 帧，偶数秒都是关键帧），
并附 `out/join.sh` 拼回；切完用解码后的画面 md5 核对过。有 Release 权限时应直接把整片传到 Release。

## 8. 踩过的坑

- 高频程序化噪声在远处会变成雪花噪点：材质里按距离淡出细节（`mats.fade`）。
- 反弹光线打到小而亮的发光面会出「萤火虫」：给它们加 `MASK_NOBOUNCE`，另放一盏显式点光源。
- 掠射角下菲涅耳会让整片湿地面变成镜子（操场看着像被淹了）：只有真正的水洼给高反射率。
- 雨丝用 alpha 混合会在亮背景上变成黑道：改成加色。
- 离相机太近的树叶/电线/草是画面杀手：镜头前十几米清空。
- 640×360×36 采样、9 个光照层时内存约 5 GB；层数再多就要分块。
- 粒子的颜色要单独想：白色花瓣在蓝紫色环境里会读成雪，改成明确的粉色才是春天。
- 没被灯照到的花和叶在冷色环境光里会发灰发紫；给叶片材质一点自发光，它们才有「透着光」的感觉。
- 时间：一个场景从零到能看约 30～60 分钟，其中构图和光的迭代占大半；每次试渲用 `still 3`（9 采样，十几秒）。
